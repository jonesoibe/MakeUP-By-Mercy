## 🚀 **HOW TO DEPLOY LIVE (5 MINUTES)**

### **FASTEST METHOD: Railway.app**

1. **Sign up**: https://railway.app
2. **Connect GitHub** (push your code there first)
3. **Create new project** → Deploy from GitHub
4. **Add environment variables**:
   ```
   PORT = 3000
   NODE_ENV = production
   EMAIL_SERVICE = gmail
   EMAIL_USER = your-email@gmail.com
   EMAIL_PASSWORD = your-app-password (16 chars)
   ```
5. **Deploy** → Get live URL instantly!

**That's it! Your website is now live.** 🎉

### **Alternative Methods:**
- **Render.com** - Free tier, similar steps
- **Heroku** - Classic hosting
- **DigitalOcean** - More control, paid

See `DEPLOYMENT.md` for detailed instructions for each platform.

## 📧 **Email Setup (Gmail)**

1. Go to: https://myaccount.google.com/apppasswords
2. Select "Mail" + "Windows Computer"
3. Google generates 16-character password
4. Copy to `.env` file:
   ```
   EMAIL_USER=your-email@gmail.com
   EMAIL_PASSWORD=xxxx xxxx xxxx xxxx
   ```
5. Restart server → Emails work!
